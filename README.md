# entra-lab
Microsoft Entra ID Lab – Tenantin rakentaminen, käyttäjähallinta ja Windows 11 ‑laitteen liittäminen  Tämä projekti dokumentoi vaiheittain rakennetun Microsoft Entra ID ‑testiympäristön. Labran tavoitteena on ymmärtää identiteettien, käyttäjien, laitteiden ja kirjautumisen hallinnan perusteet ilman maksullisia lisenssejä tai Intunea.
