# entra-lab
Tenantin rakentaminen, käyttäjähallinta ja Windows 11 ‑laitteen liittäminen
Tämä projekti dokumentoi vaiheittain rakennetun Microsoft Entra ID ‑testiympäristön.
Labran tavoitteena on ymmärtää identiteettien, käyttäjien, laitteiden ja kirjautumisen hallinnan perusteet ilman maksullisia lisenssejä tai Intunea.
Sisällysluettelo
1.Yleiskuvaus
2.Labran tavoitteet
3.Tenantin luonti
4.Käyttäjien luonti
5.Windows 11 ‑laitteen liittäminen Entraan
6.MFA ja PIN‑kirjautuminen
7.Sign‑in logs ja auditointi
8.Lopputulos
9.Jatkokehitys
